발주서의 UI 아틀라스 21종, 탐사 지도, 계절 소품 시트를 출력했다.
셀 순서는 `docs/GPT_ASSET_ORDER.md` 5장과 `assets/production.json` 참조.
`hd/`의 아이콘은 64px 셀, 상세 제작품은128px 셀이다. 창·버튼 스킨은 원본 픽셀로 그린 9-slice/상태 시트다.
`window_title`은 높이16px를 유지하는 좌우8px 가로3-slice, `scroll`은16×16 셀 안 중앙8px 폭을 사용한다.
`portrait_frame` 중앙64×64는 투명하다. 계절 소품은4열×3행,48px 셀(상세128px)이며 엔진 미등록이다.
