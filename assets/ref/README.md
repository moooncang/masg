# 인물 외형 참고 이미지 (도트 작업용)

**참고 전용. 이 이미지를 게임에 그대로 쓰거나, 축소·필터·트레이싱해서 에셋으로 만드는 것은 금지.**
도트 스프라이트·초상화는 이 그림을 보고 **새로 찍는다**. 머리 모양·색·의상·소품·표정의 기준으로만 쓴다.
게임은 전연령이므로 스프라이트·초상화는 노출 없이, 어깨 위 또는 전신 보통 복장으로 그린다.

## 도트로 옮길 때

- 16×24 워킹 스프라이트에서는 **색 덩어리 3개**로 식별한다: 머리색 / 상의색 / 하의·치마색. 위 표의 굵은 요소는 1~2픽셀이라도 넣는다 (레이나 땋은 머리 한 줄, 네르 꼬리, 세르피나 견장 금색 점, 이브레아 안경 2픽셀, 카샤 흰 숄)
- 64×64 초상화에서는 눈 색·눈매·입(카샤 붉은 입술, 네르 송곳니)·안경·귀 모양이 성격을 만든다. 여기서 표정 차이를 낸다
- 배경(가게 내부)의 분위기도 이 그림들의 나무 벽·등불 톤을 따른다
- 사장(P)은 참고 그림이 없다. 수수한 작업복, 머리색은 위 다섯과 겹치지 않게(짙은 갈색 권장)
