# 캐릭터 에셋 — 파일별 출력 완료

시안의 묘사를 유지하는 파일은 **`hd/char_*.png`, `hd/cust_*.png`, `hd/face_*.png`**다.
캐릭터·손님·복장 변형은 256×96(64×96 프레임 4개), 초상화는 128×128이다.
4프레임 순서는 서기 / 걷기 A / 같은 서기 / 걷기 B. 바닥 1px는 투명하다.

이 폴더 바로 아래에는 기존 manifest 호환용 64×24 보행 시트와 64×64 초상화도 있다.
단순화 때문에 거절된 `4d77113` 파일을 복원한 것이 아니라, 새 제작 원화에서 출력한 파일이다.
이미지 출력의 알파는 0/255이며 프레임 정렬과 정지 프레임 재사용을 적용했다.

**현재 384×216 캔버스에 작은 파일만 그린 뒤 CSS로 확대하면 시안의 디테일이 나오지 않는다.**
Claude는 [전체 납품 안내](../README.md)와 [실제 파일·프레임 목록](../production.json)을 따라
상세 파일을 더 큰 렌더 버퍼에 그린다. 엔진·manifest 수정은 이 납품에 포함하지 않았다.

`hd/characters.png`와 `hd/characters.json`은 이전 단계의 제작 원본/측정 기록이다.
게임에서는 이 불균일 원본 아틀라스 대신 새로 정렬된 인물별 `hd/char_*.png`를 사용한다.
