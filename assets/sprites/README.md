# 캐릭터 에셋

사용자가 2026-10-13에 단순화된 16×24 캐릭터를 거절하고
`docs/ux/art/characters_concept.png`의 묘사 수준을 유지하도록 지시했다.
`4d77113`의 캐릭터 6장은 철회했다. 같은 방식으로 만든 손님·초상화도 납품하지 않는다.

## 다시 제작한 캐릭터 원화

- `hd/characters.png`: RGBA 1024×1536. 레이나·네르·세르피나·이브레아·카샤·사장 순서, 각 4포즈.
- `hd/characters.json`: 24개 소스 사각형, 발 기준 피벗, 인물별 애니메이션 순서.
- 승인 시안은 외형·묘사의 참고로만 사용했다. 기존 시안을 잘라 쓰거나 축소한 파일이 아니다.
- 투명 배경은 체크무늬 위에서 확인했다. PNG에는 부드러운 알파 경계가 남아 있어 기존 발주서의 무안티앨리어싱 원본 도트 규격을 충족한 납품본은 아니다.

## Claude 연결 시 주의

현재 `src/render.js`는 16×24 고정 소스 프레임을 읽는다. 이 원화를 기존
`char_A.png` 등의 이름으로 바꾸면 잘못 잘린다. 아직 manifest와 엔진에는 연결하지 않았다.
JSON의 개별 사각형을 사용해야 하며, 256×256 균등 분할로 읽지 않는다.
프레임별 폭·높이로 인물을 늘이지 말고 공통 크기와 발 기준점을 적용한다.
정지 프레임은 0번을 재사용한다. 보행 좌우 발 교대와 가장자리 픽셀은 추가 정리가 필요하다.

시안 수준의 디테일을 실제 화면에서도 유지하려면 캐릭터를 다시 16×24로 축소하지 말고,
논리 좌표와 고해상도 렌더링을 분리해야 한다. 그 통합 작업과 픽셀 마감은 미완료다.
이 파일을 기존 발주서 1번 전체 완료로 취급하지 않는다.
