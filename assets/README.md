## Claude 연결 기준

**시안의 디테일을 보여 줄 화면에는 `sprites/hd/`, `bg/hd/`, `ui/hd/`를 사용한다.**
기본 경로는 기존 `assets/manifest.js`가 곧바로 로드할 수 있게 발주 크기에 맞춘 호환 파일이다.
16×24 인물을 그린384×216 캔버스를 CSS로 확대하는 방식만으로는 큰 원화의 눈·머리카락·장식이 살아나지 않는다.

- 논리 좌표384×216을 유지하되, 예를 들어 렌더 버퍼는1536×864로 두고4배 변환한다.
- 상세 캐릭터 소스는64×96 프레임4개, 전체256×96이다. 화면의 논리16×24 영역에 그리면 실제64×96 픽셀을 사용한다.
- 상세 초상화128×128, 일반 아이콘64×64 셀, 제작품 상세128×128 셀. 이미지 보간은 끈다.
- 창·버튼은 네이티브 도트 스킨을9-slice 또는 상태별 셀로 사용한다. `window_title`은 가로3-slice다.
- 배경 의자·가구의 실제 위치는 기존 임시 렌더 좌표와 다르다. `production.json`의 `sceneAnchors`를 시작점으로 사람·진행 바·선택 영역을 맞춘다.
- 계절 소품은48×48 셀,4열×3행으로 선제작했다. 아직 manifest에 등록하지 않았다.

기존 manifest, `src/`, 게임 데이터·대사·밸런스는 수정하지 않았다. 화면 연결은 기존 역할 분담대로 Claude 작업이다.

## 제작·검수 범위

승인 화면이나 인물 참고 사진을 잘라서 납품하지 않았다. 이미지 생성 도구로 별도의 제작 원화를 만든 뒤,
그 **새 제작 시트**에서 인물/아이템을 분리하고 프레임 정렬·픽셀 크기·팔레트·알파를 출력했다.
창과 버튼 스킨은 빈 캔버스에 원본 크기로 그렸다. 따라서 모든 그림을 처음부터16×24 등 작은 격자에서
수작업으로 찍었다는 뜻은 아니다. 승인 시안의 묘사를 유지하는 상세 출력과 이전 엔진용 호환 출력을 함께 제공한다.

PNG 검사는 크기, 알파0/255, 불투명 순검정 유무, 보행4셀, 동일 정지 프레임, 발밑 여백, 표정 파일 구분을 확인한다.
이는 그림의 모든 포즈가 완벽한 정면 보행이라는 보증이나 게임 UI 통합 완료 판정이 아니다.
보행 중 일부 포즈는3/4 방향으로 돌아가므로 연출에 맞춰 사용한다.
검수 결과는 [qa/files.json](qa/files.json), [qa/browser.json](qa/browser.json)에 있다.
