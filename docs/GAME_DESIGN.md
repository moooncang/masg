# 게임 기획 뼈대 — 골목 시술소

현재 코드에 들어 있는 시스템을 적은 것. 수치는 `src/data/config.js`가 정본이고, 여기 적힌 숫자는 참고용이다.

## 1. 코어 루프

```
개점(09:00) ─ 유지비·급여 지출 ─ 하루 이벤트 ─ 조향
   │
   ├─ 손님 도착 → 대기실(의자 수 제한) → 빈 시술실 + 빈 직원 배정 → 시술(30~60분) → 판정
   │                                         └─ 기다리다 떠남: 평판 -6
   │
마감(24:00) ─ 정산 ─ 소문 감소 ─ 구인 목록 갱신 ─ 저장 ─ 다음 날
```

플레이어가 하는 일: 직원 배치, 확장 구매, 향유 구매, 구인·해고, 이벤트 선택지, **빚 갚기**. 시술 자체는 자동.
속도 ⏸ / 1x / 2x / 4x. 1x에서 1초 = 게임 1분, 하루 = 실제 15분 (4x 약 4분).
길잡이(`src/data/tutorial.js`): 첫날·첫 손님·첫 시술·첫 마감·2~4일째 아침에 한 번씩 레이나/네르가 조작을 안내한다. "안내 그만 보기"로 끄고 설정 창에서 다시 켠다.
탐사대: 탐사 창에서 고른 직원은 `s.party` 에 들어가 시술 배정에서 빠지고 계단 앞에 모인다. 출발하면 비워진다.
레이나 조향: 조향실 배치 시 매일 2병(+선반), 접수대 배치 시에도 틈틈이 1병.

### 게임 목표 — 카르벤 상단 빚 (CONFIG.DEBT)

- 개업 자금 **금 250** 을 **30일째 아침**까지 갚는다. 가게 창 → 오늘의 영업에서 금 1 / 5 / 10 / 가능한 만큼 단위로 갚는다. 하단 왼쪽 칩이 남은 빚과 D-day 를 항상 보여 준다.
- 중간 독촉: 10일째 아침 금 40, 20일째 아침 금 120 미만이면 경고 모달(불이익 없음).
- 기한을 넘기면 한 번만 연장: 남은 빚에 이자 25%, 10일 추가. 두 번째 기한도 넘기면 폐업 모달 → 새 게임 또는 빚 없는 자유 영업(기록 없음).
- 다 갚으면 "간판을 달았다" 모달, 평판 +100, 업적 "빚 청산"(금 20) · "절반은 갚았다" · 숨김 "서둘러 갚은 빚"(20일째 전). 이후는 자유 영업.
- 밸런스 기준(자동 플레이 시뮬): 아무것도 안 사면 30일 소지금 약 금 520, 베드 4개까지 투자하면 약 금 600. 빚은 그 절반 — 큰 확장(금 15~70)을 몇 개 사면 압박이 생긴다. 유지비 하루 은 8 + 베드당 은 4 + 평판 단계당 금 1.5.

## 4. 시술 판정

```
base  = 손기술 + 감각×0.6 + 친절×0.4
score = 50 + (base − 난이도×2.2)×6 + 향유 보너스 + 보정 ± 10(난수)
```
보정: 향유 필요한데 없으면 −15, 피로 75↑ −20, 네르 대기 보조 +4, 사장이 종족 예민 부위 담당 +5.

| 등급 | 점수 | 대금 | 평판 | 경험치 |
|---|---|---|---|---|
| S | 85+ | ×1.5 | +6 | ×1.5 |
| A | 70+ | ×1.2 | +4 | ×1.2 |
| B | 50+ | ×1.0 | +2 | ×1.0 |
| C | 미만 | ×0.6 | −4 | ×0.7 |

## 6. 직원

능력치 1~10: 손기술(technique) / 감각(sense) / 체력(stamina) / 친절(charm).
- 피로: 시술당 +14, 쉬면 분당 −0.25, 75↑면 판정 −20, 100이면 배정 안 됨. 마감 시 −60(2층 리모델링 ×2)
- 경험치: 난이도×10×등급 배율. 레벨당 100×레벨. 레벨업 시 무작위 능력 +1
- 배치: 시술 / 휴식. 레이나만 접수(손님 유입 +15%) / 조향 추가
- 구인: 매일 3명. 고용비 금1.5 + 평판단계×금1.5, 일당 은3 + 단계×은2. 능력은 평판 단계에 비례
- 창업 멤버(사장·레이나·네르)는 해고 불가, 급여 없음

## 7-1. 단골

일반 손님이 S/A 등급을 받으면 15% 확률로 단골이 된다(최대 20명). 단골은 손님 생성의 30%를 차지하고, 인내심 +30%, 대금 +15%, 점수 +3, 평판 +1. 기다리다 떠나면 단골 명단에서 빠진다.

## 7-2. 구인 특성

구인 후보의 70%가 특성 1개를 가진다: 성실(피로 −30%) / 눈썰미(점수 +4) / 수다쟁이(친절 +1, 소문 +0.5) / 야행성(심야 +10, 낮 −3) / 손이 큼(대금 +10%, 향유 2배). 레이나 "조향사", 네르 "성장기(경험치 1.5배)"는 고정.

## 7-3. 칸막이 트레이드오프

방음벽이 없으면: 혈맥 시술 중 대기 손님이 30% 확률로 엿듣는다(소문 +0.5, 그중 25%는 슬그머니 나감). 사장이 엘리트 손님을 시술하면 15% 확률로 레이나·네르가 질투한다(관계 −1, 연출 로그). 방음벽을 사면 둘 다 사라지고 소문 상승도 −60%. 뒷문은 상위 직업 손님을 저녁에 불러오고 혈맥 소문 −1.

## 7-4. 업적

76개, 6분류(가게/평판/확장/향유/던전/관계). `src/data/achievements.js`. `when: { 지표: 최소값 }` 로 적고 지표는 `Sim.metrics()` 가 만든다(시술 수, S 횟수, 수입, 일수, 완벽한 날, 만석, 심야, 금고 최대, 평판 단계, 단골, 감찰, 조용한 날, 기사단 손님, 베드, 직원, 확장, 레벨, 조향·구매·사용 병수, 월하향, 탐사·깊이·마력핵·제작·설비, 대화·선물·출장, 관계 최대/최소, 이야기 수, 영입 수 등). 보상은 돈 또는 평판. `hidden` 은 달성 전 ???. `key` 는 엘리트 영입 조건.

## 7-5. 가게 규모

- 시술 베드 최대 8 (확장 room3~room8, 평판 단계와 선행 조건). 캔버스에 4열×2행
- 직원 정원: 기본 5(사장 포함). 2층 직원 숙소 +2, 2층 리모델링 +2, 별채 +3 → 최대 12. 영입 인물은 정원을 넘어도 들어온다

- 유지비 = 은3 + 베드당 은1.5 + 평판 단계당 은6 + 급여

## 7-6. 던전(심연구) 파밍과 제작

- 던전 탭에서 깊이(1층 입구 동굴 2h / 2층 마력 수맥 4h, 입소문 / 3층 심연 정원 6h, 단골 가게)와 파티(최대 3명, 사장 제외, 피로 70 미만, 조향 중 제외, 깊이별 최소 레벨 1/3/5)를 골라 출발. 당일 23:30 전에 돌아와야 한다
- 전리품: 깊이별 표에서 (lootRolls + 체력/4) 회 굴린다. 감각이 높거나 '측정구' 특성이면 희귀 재료 가중치가 오른다. 2·3층은 15%/35%로 결을 달고 돌아온다(피로 100). '기사단 체력'은 면역
- 재료 7종: 진정초, 온천수, 마력 결정, 동굴 거미줄, 월하 꽃, 용린 조각, 마력핵 파편. 상단에 팔 수도 있다
- 제작 10종 (`src/data/items.js`): 향유 3종(월하향은 증류기+해금), 소모품 4종(온열 수건 피로 −40 / 진정 향초 하루 인내심 +40% / 마력 부적 하루 점수 +8 / 회복 강장제 사장 피로 0), 설비 3종(거미줄 시트 대금 +8% / 용린 베드 보강 시술 시간 −10% / 마력 등불 심야 +50%, 소문 −1/일)
- 탐사 경험치: 깊이×15

관계 0~100: 낯섦 0 / 안면 20 / 신뢰 45 / 각별 75.
