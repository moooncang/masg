# 게임 기획 뼈대 — 골목 시술소

현재 코드에 들어 있는 시스템을 적은 것. 수치는 `src/data/config.js`가 정본이고, 여기 적힌 숫자는 참고용이다.

## 1. 코어 루프

```
개점(09:00) ─ 유지비·급여 지출 ─ 하루 이벤트 ─ 조향
   │
   ├─ 손님 도착 → 대기실(의자 수 제한) → 빈 시술실 + 빈 직원 배정 → 시술(30~60분) → 판정
   │                                         └─ 기다리다 떠남: 평판 -6
   │
마감(24:00) ─ 정산 ─ 소문 감소 ─ 구인 목록 갱신 ─ 저장 ─ 다음 날
```

플레이어가 하는 일: 직원 배치, 확장 구매, 향유 구매, 구인·해고, 이벤트 선택지. 시술 자체는 자동.
속도 ⏸ / 1x / 2x / 4x. 1x에서 하루 = 실제 3분.

## 2. 시간대

| 시간대 | 시각 | 손님 배율 | 비고 |
|---|---|---|---|
| 낮 | 09–17 | 1.0 | 일반 손님 |
| 저녁 | 17–21 | 1.3 | 체면 있는 손님이 늘어남 |
| 심야 | 21–24 | 0.35 | 예약제 메뉴(혈맥)와 VIP만 |

## 3. 자원

| 자원 | 설명 |
|---|---|
| 소지금 | 동화 단위. 금1=은10=동1,000 |
| 평판 | 수치 0~. 단계: 무명 0 / 입소문 150 / 단골 가게 450 / 골목 명소 900. 손님층·메뉴·확장·VIP 해금 |
| 소문 | 0~100. 혈맥 시술·축제로 오른다. 70이면 감찰(평판 -30, 소문 -50, 당일 폐점). 매일 -4. 방음벽이면 상승 -60% |
| 향유 | 진정(은1동50) / 온열(은3). 레이나가 조향실에 있으면 매일 2병(선반 +1). 카샤 관계 45↑면 20% 할인 |

## 4. 시술 판정

```
base  = 손기술 + 감각×0.6 + 친절×0.4
score = 50 + (base − 난이도×2.2)×6 + 향유 보너스 + 보정 ± 10(난수)
```
보정: 향유 필요한데 없으면 −15, 피로 75↑ −20, 네르 대기 보조 +4, 사장이 종족 예민 부위 담당 +5.

| 등급 | 점수 | 대금 | 평판 | 경험치 |
|---|---|---|---|---|
| S | 85+ | ×1.5 | +6 | ×1.5 |
| A | 70+ | ×1.2 | +4 | ×1.2 |
| B | 50+ | ×1.0 | +2 | ×1.0 |
| C | 미만 | ×0.6 | −4 | ×0.7 |

## 5. 메뉴

| 메뉴 | 가격 | 시간 | 난이도 | 깊이 | 해금 | 향유 | 소문 |
|---|---|---|---|---|---|---|---|
| 근육풀이 | 은2 | 30 | 1 | 표층 | 무명 | – | 0 |
| 향유 시술 | 은5 | 45 | 2 | 표층 | 무명 | 진정 | +1 |
| 결풀이·표층 | 은8 | 45 | 3 | 표층 | 입소문 | – | +1 |
| 결풀이·혈맥 | 금2 | 60 | 5 | 혈맥 | 단골 가게 | 온열 | +3, 예약제 |

심결은 메뉴에 없다. 관계 이벤트에서만 열린다(원작 원칙 유지).

## 6. 직원

능력치 1~10: 손기술(technique) / 감각(sense) / 체력(stamina) / 친절(charm).
- 피로: 시술당 +14, 쉬면 분당 −0.25, 75↑면 판정 −20, 100이면 배정 안 됨. 마감 시 −60(2층 리모델링 ×2)
- 경험치: 난이도×10×등급 배율. 레벨당 100×레벨. 레벨업 시 무작위 능력 +1
- 배치: 시술 / 휴식. 레이나만 접수(손님 유입 +15%) / 조향 추가
- 구인: 매일 3명. 고용비 금1.5 + 평판단계×금1.5, 일당 은3 + 단계×은2. 능력은 평판 단계에 비례
- 창업 멤버(사장·레이나·네르)는 해고 불가, 급여 없음

## 8. 인물과 관계

관계 0~100: 낯섦 0 / 안면 20 / 신뢰 45 / 각별 75.
직원은 시술 성공마다 +1. VIP는 시술 등급에 따라 S+8 A+5 B+2 C−3, 기다리다 떠나면 −5.

| 코드 | 이름 | 역할 | 등장 조건 | 훅 (경영 연결) |
|---|---|---|---|---|
| A | 레이나 | 직원·조향/접수 | 처음부터 | 접수/조향 배치 선택. 관계 45: 자기 시술 거부 이벤트 |
| B | 네르 | 직원·견습 | 처음부터 | 성장 빠름, 보조 보너스. 관계 45: 꼬리 결 이벤트 |
| C | 세르피나 | VIP·기사단 부단장 | 입소문 + 소문 40↑ | 감찰로 첫 등장 → 지정 시술소(기사단 손님 유입) |
| D | 이브레아 | VIP·마탑 연구원 | 입소문 | 측정 데이터 퀘스트 (N회 시술 → 보상) |
| E | 카샤 | VIP·상단 주인 | 단골 가게 | 전속 계약(수입↑ 자유↓), 향유 재료 할인 |

VIP는 해금 후 이틀에 한 번꼴로 올 수 있다. 저녁·심야에 더 자주.

## 9. 이벤트

- 하루 이벤트(개점 시 1개, 확률): 대원정 귀환 ×2.0 / 장마 ×0.6 / 축제 ×1.5 소문+3 / 경쟁 시술소 ×0.75 / 마탑 사고 ×1.3 혈맥↑
- 조건 이벤트(하루 1개, 30분마다 체크): 감찰 / VIP 첫 등장 3종 / 레이나·네르 관계 45
- 효과 키: `spawnMul, veinBias, rumor, rep, money, relation{코드:n}, closeToday`

## 10. GPT가 채울 것

1. **훅 이벤트 설계** — 인물별 2~3단계 (관계 20/45/75)의 제목·본문·선택지(2~3개)·선택별 효과. 효과는 9장의 키로. 현재 엔진은 선택지가 없고 "확인"만 있다 → 선택지 구조는 Claude에게 요청 항목으로 적을 것
2. **하루 이벤트 10종 추가** — 세계관(성문구 의회, 운하변 상단, 첨탑구 마탑, 주둔지 기사단, 심연구)을 활용
3. **손님 대사 풀** — 입장/만족/불만 + 종족·직업별 한 줄
4. **밸런스 곡선** — 1~30일 목표 수입·평판·확장 순서. 지금은 7일이면 단골 가게에 닿는데 이게 적당한지
5. **2층·후반 콘텐츠** — 직원 숙소(피로), 사장 거처, 출장 시술, 경쟁 시술소 대응
6. **엔딩 또는 목표** — 고정 엔딩은 두지 않는 게 원작 원칙. "골목 명소" 달성 이후의 목표를 제안

## 11. 미결 (작가님 결정)

- 가제: 현재 "골목 시술소". 다른 이름이면 `config.js`의 SHOP_DEFAULT_NAME과 README를 바꾼다
- 시술 미니게임을 넣을지: 지금은 자동 판정. 넣는다면 VIP 한정으로 하는 걸 제안
- 사운드: 미착수
- 사장 스프라이트 외형: 정해진 게 없다. GPT가 안을 내고 작가님이 고른다
