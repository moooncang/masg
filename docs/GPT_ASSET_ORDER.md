# GPT 에셋 발주서 — 지금부터 제작 단계

> **제작 결과:** 아래 항목의 파일은 [에셋 납품 안내](../assets/README.md)에 정리했다. 사용자가 단순화된 캐릭터를 거절하고 승인 시안 수준을 요구하여, 기존 규격의 호환 PNG와 더 큰 상세 PNG를 함께 제공했다. 화면에는 상세 출력을 우선 연결한다. 제작 방법·검수 범위·기존 규격과의 차이도 납품 안내에 명시했다.

> **지시 (2026-10-13, 작가님 확정)**
> UX v3 설계는 승인됐다. **추가 승인 요청, 시안 재제출, 방향 확인 질문 없이 아래 목록을 순서대로 바로 제작해서 저장소에 올린다.**
> 판단이 필요한 세부는 이 문서와 `docs/ASSET_SPEC.md`, `assets/ref/README.md`의 기본값을 따르고, 정한 내용은 커밋 메시지에 한 줄로 적는다.
> 목업 PNG를 잘라 쓰거나 축소해서 납품하지 않는다. 전부 **원본 픽셀 크기로 새로 찍은 PNG**여야 한다.

## 0. 납품 규칙

- 경로와 파일명은 아래 표 그대로. 틀리면 엔진이 못 읽는다. 영문 소문자·숫자·밑줄만
- PNG, 투명 배경(배경 이미지 제외), 원본 픽셀 크기 그대로. 업스케일·안티앨리어싱·블러 금지
- 팔레트: 외곽선 `#211c29`, 그림자 `#382a32`, 목재 `#704b3b`, 밝은 목재 `#a57950`, 황동 `#d7ac62`, 글자 `#eee1bc`, 긍정 `#91ad74`, 손실 `#c97868`. 캐릭터는 인물 고유색 추가. 순검정 외곽선 금지
- 광원은 좌상단. 모든 아이콘과 창이 같은 규칙
- 한 묶음(아래 1~8의 한 항목)이 끝날 때마다 커밋한다. 전부 모아서 한 번에 올리지 않는다
- 올린 뒤 `assets/manifest.js`를 건드리지 않는다. 경로는 이미 등록돼 있다. 화면에 반영은 Claude가 한다
- 인물 외형 정본은 `assets/ref/ref_A~E.webp` + `docs/LORE.md`. 목업과 다르면 정본이 우선. **세르피나는 갑옷 없음(제복만)**, 카샤는 뾰족 귀·갈색 피부, 이브레아는 색 들어간 둥근 안경

## 2. 자리 좌표표 `assets/layout_hd.json`

배경을 그린 GPT가 픽셀을 재서 작성한다. 전부 세계 px, 정수. 아래 키 전부 필수.

```json
{
  "world": [1672, 941],
  "entrance": [650, 900],
  "waypoints": { "hall": [560, 720], "corridor": [560, 520], "seam": 335, "bedAisle": [[720, 335], [980, 335], [1250, 335], [1500, 335]] },
  "reception": { "spots": [[296, 232], [372, 232]] },
  "waiting": {
    "sofa":   [[215, 560], [290, 560], [365, 560]],
    "chairs": [[232, 735], [352, 735]],
    "stand":  [[560, 470], [560, 560], [560, 650]],
    "bubble": [0, -72]
  },
  "rooms": [
    { "rect": [600, 66, 238, 262], "lie": [655, 215], "staff": [780, 210], "bar": [650, 118, 80, 12], "plate": [735, 300], "lock": [735, 215] },
    { "rect": [845, 66, 273, 262], "lie": [0, 0], "staff": [0, 0], "bar": [0, 0, 80, 12], "plate": [0, 0], "lock": [0, 0] },
    { "rect": [1128, 66, 253, 262] },
    { "rect": [1381, 66, 263, 262] },
    { "rect": [600, 349, 238, 269] },
    { "rect": [845, 349, 273, 269] },
    { "rect": [1128, 349, 253, 269] },
    { "rect": [1381, 349, 263, 269] }
  ],
  "brew":   { "spots": [[890, 700]] },
  "idle":   [[620, 760], [700, 760], [780, 760], [620, 830], [700, 830], [780, 830]],

```

- `rect` 는 방 전체(클릭 영역). `lie` 는 누운 스프라이트의 **머리 끝(왼쪽 중앙)**이 베개 위에 오는 점. `staff` 는 시술 직원의 **발**이 오는 점(시안처럼 베드 뒤, 베개 반대편). `bar` 는 녹색 진행 바 x,y,w,h. `plate` 는 번호판 중심. `lock` 은 자물쇠 중심
- `sofa`·`chairs` 는 앉은 스프라이트의 **엉덩이**가 오는 점. 쿠션 앞선 바로 위
- `waypoints.seam` 은 베드 1열과 2열 사이 통로의 y, `bedAisle` 은 각 열 사이 세로 통로 입구. 손님은 입구 → hall → corridor → (seam, bedAisle) → 베드 순으로만 걷는다
- `hud.safeTop/safeBottom` 은 HUD·도구띠가 덮는 높이. 그 안에는 중요한 가구를 두지 않는다
- 위 숫자는 Claude의 눈대중 예시다. **전부 실측으로 바꾼다.** 예시값을 그대로 두면 사람이 가구에 겹친다

## 10. 납품 순서와 커밋

1. 배경 3장 → 2. `layout_hd.json` → 3. 캐릭터 시트 19 + 눕기 13 + 머리 마스크 10 + 그림자 → 4. 초상 25 → 5. 소품·감정 → 6. UI 스킨 → 7. 로딩·타이틀 → 8. 합성 검수.
각 단계마다 커밋. 커밋 메시지에 단계 번호와 정한 기본값 한 줄. 코드·대사·문서 수정 금지. 질문 대신 기본값으로 정하고 메시지에 적는다.
