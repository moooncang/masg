## 아트 시안 한계

고해상도 생성 목업은 레이아웃·재질·아이콘 방향을 확인하기 위한 자료다. 방 마스크·출발 가능 상태·경험 분모·업적 필터·인물 이름은 최종 코드 데이터가 우선한다. 생성물의 일부 프레임이나 수치를 검수 없이 자르거나 그대로 넣지 않는다. 실제 픽셀 격자, 투명도, 폰트, 64px 초상화와 16×24 워킹 프레임은 별도 제작·검수 대상이다.
