## 2. 공통 상태 규칙

| 대상 | 상태 | 표현·처리 |
|---|---|---|
| 버튼 | 가능 | 기본/포커스/누름 스킨 |
| 버튼 | 불가 | 비활성 스킨+정확한 사유. 조건 둘 이상이면 모두 표시 |
| 구매 | 재고·돈 변동 | 클릭 직전 가격·보유액 다시 판정. 실패해도 선택·스크롤 유지 |
| 선택 대상 | 사라짐 | 대상이 없음을 알리고 목록으로 복귀. 다른 대상을 자동 실행하지 않음 |
| 목록 | 실시간 갱신 | 값만 갱신. 1초마다 DOM 전체를 교체해 포커스·입력을 빼앗지 않음 |
| 가방 | 0개 | 슬롯 비우기+숫자0, 상세 용도·확보 경로 유지 |
| 레시피 | 부족 | 재료별 보유/필요와 부족 표시. 완제품 개수는 별도 |
| 설비 | 제작 완료 | 설치됨, 중복 제작 버튼 없음 |
| 업적 | 숨김 | 이름·보상·조건·태그까지 비노출. 접근성 이름도 ??? |
| 탐사 | 참가 불가 | 사장/업무 중/조향/피로≥70/레벨/늦은 시각/미해금 층 사유 |
| 탐사 | 진행 중 | 새 편성 없음, 현재 인원·층·시각만 |
| 영입 | 미충족 | 조건 각각 진행 표시 |
| 영입 | 제안 대기 | 직접 영입 호출 금지, 이벤트 흐름으로 연결 |
| 영입 | 거절/완료 | 실제 fired/recruited 상태로 구분. 재제안 가능처럼 표시하지 않음 |
| 저장 | 실패 | 실제 반환값 기준 실패 표시. 저장됐다고 거짓 안내하지 않음 |

## 3. 레이어·시간·알림

레이어 순서: 배경 → 사람·진행 → HUD·도구띠 → 일반 창 → 모달 → 짧은 알림·툴팁. 알림은 모달 선택지·닫기·구매 버튼과 겹치지 않는다. 모달 중 아래 창의 클릭·포커스를 막는다.

일반 관리 창은 현행 탭처럼 시간이 흐른다. HUD 정지는 사용할 수 있다. 강제 선택·대화 모달만 원래 속도를 저장하고 정지한다. 연결된 모달 큐 전체가 끝난 뒤 단 한 번 복구하며 0/1/2/4 각각 보존한다. 현재 코드의 `modalPrevSpeed || 1`은 이 규칙을 충족하지 못하므로 수정 대상이다.

선택 가능한 대화는 취소 가능한 단계에서 닫고, 이미 선택한 결과는 다시 실행하지 않는다. 모달을 닫아도 게임 데이터가 되돌아가는 것처럼 표현하지 않는다. 반복 이벤트와 영입 같은 일회성 이벤트는 원문 데이터에 따른다.

## 4. 아트 규격·파일 연결

기존 경로를 유지하는 생산물: `char_P/A/B/C/D/E.png` 64×24, 손님10장 64×24, `face_A~E_2.png` 64×64, `floor1(_night).png` 384×216. 일반 직원은 최신 스펙대로 손님 스프라이트를 재사용한다.

추가 UI atlas 제안(미제작):

| atlas | 네이티브 규격 | 순서 |
|---|---|---|
| currency | 48×16 | 금/은/동 |
| menu | 128×16 | 가게/직원/확장/향유/탐사/관계/업적/설정 |
| materials | 112×16 | herb/spring/crystal/silk/moonflower/scale/core |
| products | 160×16 | calm/warm/moon/towel/candle/charm/tonic/sheet/bedplate/lamp |
| window | 24×24 | 8px 모서리 9-slice |
| buttons | 96×24 | 24px셀: 기본/포커스/누름/비활성 |
| slots | 96×24 | 24px셀: 기본/선택/빈 슬롯/잠금 |

재료 식별: 진정초=잎 묶음, 온천수=파란 물병, 마력 결정=푸른 각진 결정, 거미줄=회백 실타래, 월하 꽃=달 표식 흰 꽃, 용린=겹친 비늘, 마력핵=보라 금이 간 핵. 완제품은 재료보다 완성된 실루엣으로 구분한다. 강장제는 진정 향유와 병 모양·표식이 달라야 한다.

소형 아이콘을 큰 상세 그림으로 쓸 때 정수배 확대하거나 별도 32px 상세를 만든다. 16px 셀을 비정수로 늘리지 않는다. 한 이미지에서 생성된 다양한 픽셀 밀도를 그대로 합성하지 않는다. PNG 시안은 아트 지시 자료이고 실제 atlas가 아니다.

## 6. 순서와 완료 기준

1. 최신 콘텐츠·세이브를 유지한 채 공통 도트 스킨, HUD, 8메뉴와 창 전환을 구현한다.
2. 직원·확장·향유·장부·설정을 새 창에 연결한다.
3. 탐사→가방→제작, 영입 상태, 훈장첩을 연결한다.
4. 모달·포커스·알림·모바일을 검증하고 검토 문서의 확인 항목을 해결한다.
5. 별도 제작된 네이티브 에셋을 연결하고 U01~U36을 수행한다.

완료는 ‘그림과 닮음’과 ‘모든 기존 기능 조작 가능’을 동시에 만족할 때다. 승인된 이미지의 분위기를 빌려 다시 웹 대시보드를 만드는 것은 완료가 아니다.
