1. 기존 `LORE.md`의 인물 정체성, A~E 코드, 전연령 경영물, 심결 비상품화 원칙을 유지한다.

4. **새 구현의 경제 수치 정본은 03, 운영 순서는 04, 기존 콘텐츠 효과는05·추가 콘텐츠는08, 성장과 전문화는07, 검수 기준은06이다.** 다른 문서의 사례는 정본을 덮어쓰지 않는다.

플레이타임은 콘텐츠 개수로 확정하지 않는다. 기본 영업 3분×120일=6시간이며, 준비·정산·독서·일시정지 시간이 추가된다. 2배속이면 영업 시간은 3시간으로 감소한다. **첫 주기 8~12시간**은 1배속 중심 플레이의 목표일 뿐이며, 실제 측정 후 수정한다. 반복 플레이는 다른 전문화·시설 배치·계약 조합으로 유도한다. 실시간 출석 보상, 오프라인 손실, 강제 초기화는 없다.

## 가장 중요한 다섯 가지 결정

1. 시술은 자동 진행하고, 플레이어는 서비스 구성·가격·예약·교대·투자를 결정한다. 반복 클릭형 마사지 미니게임은 넣지 않는다.
2. 결과 점수와 고객 만족을 분리한다. 기술이 좋아도 오래 기다리거나 지나치게 비싸면 재방문하지 않는다.
3. 명성과 최근 평가는 분리한다. 성장은 누적되지만 오늘의 운영 문제는 실제 방문과 현금에 영향을 준다.
4. 전문화는 상호 배타적인 운영 정책이다. 모든 보너스를 동시에 얻을 수 없으며 충분히 예고하고 바꿀 수 있다.
5. 콘텐츠는 기존 시스템의 조건을 바꾼다. 이름만 바뀐 구매 항목이나 보상 없는 수집 목록을 늘리지 않는다.
