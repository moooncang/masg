# 04. 운영·직원·시설 명세

## 1. 고객과 방의 상태

고객: `예약대기 → 도착 → 접수 → 대기 → 시술 → 결제 → 퇴장`. 취소/노쇼/거절/대기이탈은 별도 종료 상태다. 각 고객의 완료 거래는 하나다. 접수는 즉시 상태 판정이며 전담 직원이 없다고 통과 불가하지 않는다. 접수 담당자는 응대 품질을 올리는 역할이다.

방: `미개설/공사/사용가능/예약보호/시술중/정리중/청소중`. 시술실마다 한 고객·한 시술자만. 정리10분 동안 해당 직원도 점유한다. 정리 종료 후 청결을8 회복하고, 시술 완료 때 청결12 감소한다. 즉 일반 시술 한 사이클 청결 순감소4. 별도 청소20분은 청결+40, 최대100. 시작 청결30 미만이면 방을 폐쇄하고 청소 필요 표시. 자동청소 기준50 미만은 기본 켬이다. 바닥 청결 같은 두 번째 불투명 게이지는 추가하지 않는다.

### 같은 시각의 처리 순서

1. 납품·시술완료·정리완료·청소완료·휴식완료 처리.
2. 완료 거래와 재료 소비 확정, 직원/방 점유 해제.
3. 근무표 전환 및 대기 중 교대 명령 적용.
4. 예약 도착·현장 방문 기회·취소 반영.
5. 대기 인내심 감소 후 만료 처리. 단, 바로 이 시각 도착한 고객은 감소하지 않는다.
6. 예약 우선 배정 → 현장 배정 → 자동청소 → 자동휴식.
7. 시간 기반 사건 조건 평가 및 마감 여부 확인.

기본 1분 단위의 같은 결과가 1x/4x에서 나와야 한다. 화면 프레임 수는 경제 계산에 영향을 주지 않는다. 시작 시 인내심이 남아 있어야 하며, 인내심0과 자리가 나는 시각이 겹치면 이탈을 우선하는 규칙을 UI 예상에 동일하게 사용한다.

## 2. 배정 정책

설정은 가게 전체 기본값+예약 개별 지정. 무료 방과 자격 있는 근무 직원이 모두 필요하다. 자격 없는 직원에게 고가 서비스를 자동 배정하지 않는다.

1. 현재부터 `시술분+정리10분` 안에 해당 방·직원 예약이 있으면 현장 배정 제외.
2. 시작 피로80 이상 직원 제외. 재료 부족·청결30 미만 방 제외.
3. 예약시각 도래 고객을 예약시각→도착순으로 먼저 배정. 이후 현장 FIFO.
4. 직원 선택 정책: 균형형(기본)은 예상 Q60 미만 후보 제외 후 가장 낮은 피로, 품질형은 예상 Q 높은 순, 교육형은 Q60 이상 후보 중 해당 군숙련 낮은 순. 동점은 피로→직원ID 순.
5. 조건을 만족하는 직원이 없으면 ‘자격/품질 부족으로 보류’를 표시한다. 개별 고객에 한해 점주가 낮은 예측 품질을 확인하고 진행할 수 있지만 자격 제한은 무시 불가.

예약 보호로 방이 놀고 있으면 사유와 해제 시각을 표시한다. 돈을 더 낸 손님이 줄을 몰래 앞지르는 임의 로직은 없다. 현장 손님에게 예상대기를 고지하고, 인내심을 넘으면 입장 대신 다음 시간 예약을 제안한다.

## 3. 예약

T1 해금. 15분 간격 시작시각, 당일부터7일 후까지, 09~24시 중 완료+정리가 들어오는 시간. 방·직원·재료가 모두 충족되는 시간만 제시한다. 예약 점유시간은 시술+정리시간을 15분 단위로 올림한다. 남는 분은 예약 완충시간이며 다음 예약을 앞당기지 않는다. 현장 배정의 충돌 검사도 이 점유시간을 기준으로 한다. 동일 자원을 겹쳐 잡을 수 없다. 예약은 고객 한 명의 서비스 한 건이다. 단체 의뢰는 여러 예약으로 분해한다.

- 예약 시 메뉴·고지가·방·담당자·시각을 고정. 보증금20% 수령. 가격 변경 영향 없음.
- 재료: 현재 재고 또는 해당 시각 전에 확정 도착할 발주에서 필요한 수량을 할당한다. ‘재고’와 ‘예약 할당’과 ‘현장 사용 가능’을 구분한다. 납품 미확정분으로 예약 불가.
- 고객 도착: 예약시각-5~+5분 균등. 실제 도착시각은 예약 생성 시 저장. 일찍 와도 빈 시간에 조기 시술하지 않으며 시각까지 휴게 대기.
- 기본 노쇼 확률5%, 겨울+5%p, 예약 알림 정책(예약당10동) -3%p, 단골등급2 이상 -2%p. 최종0~20%. 예약 확정 때 해당 날짜의 알려진 계절 조건으로 고정.
- 15분 지각까지 예약보호. 그때 미도착이면 노쇼, 자원 해제. 보증금은 취소수수료 매출로1회 전환하되 ‘시술매출’과 분리한다. 반복 노쇼로 단골을 영구 차단하지 않는다.
- 고객이 전날까지 취소: 보증금 전액 반환. 당일 고객 취소: 보증금50% 반환, 나머지 취소수수료. 점주 취소: 전액 반환·만족30 기록·단골충성-10.
- 재료 납품 지연/직원 결근: 같은 가격·동등 자격 직원으로 바꾸는 제안. 고객 수락은 단골이면90%, 일반70%; 난수는 변경 제안당 저장. 거절하면 전액환불, 점주 취소로 처리. 더 저렴한 대체 메뉴면 차액 환불.
- 예약 취소 후 재예약으로 수수료를 반복 발생시키지 않는다. 동일 고객·같은 날짜 변경은 원거래에 연결하고 차액만 정산한다.
- VIP는 영업 완료 하루를 사이에 두고 재예약 가능. 우연한 방문과 플레이어 초대 중 중복 생성 불가. ‘오늘 대기중’ VIP를 예약 목록에 다시 넣지 않는다.

## 4. 직원과 교대

정원은 사장 포함8명. 사장·레이나·네르는 고정, 일반 직원 최대5명. 현재 3인 시작을 유지하되 추가 인력에는 유휴시간·일일급여가 생긴다.

근무 블록: 09~13/13~17/17~21/21~24. 고용 직원은 기본 하루2블록 근무, 한 블록 안에 휴식 포함. 세 번째 블록은 기본일급×블록분/480 추가급여, 네 번째 금지. 사장은 최대3블록이며 추가급여 없음. 블록 중 시술이 끝나지 않으면 마칠 때까지 근무하고 연장분은 기본일급/480×1.5/분 지급, 블록 추가급여와 같은 분에 중복 부과하지 않는다.

비근무일은 유급휴무30% 일급. 창업 직원도 동일. 낮은 비용 때문에 직원 무한고용 후 전원 대기시키는 전략은 정원과 휴무급여로 제한한다. 최소 두 블록을 강제하지 않으며 한 블록 근무는 일급75%, 두 블록은100%다. 당일 준비에서 확정한 급여를 보여준다.

| 고용 등급 | 주능력 범위 | 일급 | 채용비 | 출현 |
|---|---:|---:|---:|---|
| 견습 | 2~4 | 250 | 1,000 | T1 |
| 숙련 | 4~6 | 400 | 2,400 | T1 |
| 전문 | 6~8 | 550 | 4,000 | T2 |
| 수석 | 7~9 | 700 | 6,000 | T3 |

후보3명은 3일마다 교체, 현재 후보 즐겨찾기1명은 다음 갱신까지 유지 가능. 채용 후 즉시 근무표에 빈 블록을 배정해야 일한다. 후보 재추첨 버튼은 없다. 능력 총합은 견습12/숙련18/전문24/수석28을 기준 ±2, 능력 범위 안에서 배분. 특성은 장점1/단점1. 임금은 매일 랜덤 변화하지 않는다.

일반 직원 해고는 비시술 상태에서 가능, 예고 없이 당일 해고 시 일급1일의 정리금. 예약 담당자는 먼저 대체해야 한다. 고정 멤버 해고 불가가 무임금 착취 보너스로 기능하지 않도록 기본급을 준다.

### 피로

R/E 시술 피로 = `round(시술분/45 × (18-체력×0.8))`, 최소5. H는 이 값×0.8 후 반올림. 정리·청소·접수·조향·교육은 근무15분마다 피로+1. 시술 중에는 이 시간 피로를 추가로 더하지 않는다.

휴식/비근무는 분당0.35 회복, 휴게실 배치 시0.50. 밤 마감→다음 준비에는 모든 직원 피로-35, 적합한 기숙 지원실이 있으면-50. 자동휴식은 시작피로65 이상이면 새 일을 받지 않고35 이하에서 복귀. 예약이 예정되어 있더라도 피로80의 금지선을 깨지 않으며 일정 충돌 경고를 낸다.

기본 자동휴식은 시술이나 납품 생산을 중간 취소하지 않고 완료 직후 적용한다. 점주는 임계값을50~75, 복귀를20~45 범위에서 설정할 수 있다. 예약화면의 가용성 계산에도 휴식 예상시간을 반영한다.

### 성장과 교육

기본 능력1~10. 군숙련 R/H/E 각각0~5, 누적 성공점수 기준0/20/60/140/280/500. B이상 시술은1점, A이상2점; 둘을 중복 합산하지 않는다. 레이나는 H1, 네르는 R0, 사장은 R1/E0으로 시작한다. 03의 품질 예시는 숙련0인 가정 사례다.

기존 무작위 레벨업은 대체한다. 직원 개인의 누적 경력점수100마다 해당 직원 교육권1, 시술완료1점·A이상 추가1점. 교육권 소비+400동+근무120분으로 선택한 기본능력+1, 능력10 상한. 직원별7일에1회. 교실 지원실이면90분. 교육 중 예약 배정 불가, 중단 시 경과시간만 보존하고 비용/권은 재청구하지 않는다. 군숙련은 실전으로 올라가고 교육권으로 구매하지 않는다.

### 12개 일반 직원 특성

각 효과는 한 번만 적용하고 동일 특성 중복 불가. 비용감소와 시술·정리·조향 시간감소는 총합30% 상한. 교육·시험은 항목별 고정시간과 최저값을 따른다.

| ID | 특성 | 효과 |
|---|---|---|
| T01 | 섬세한 손 | R 품질+3 |
| T02 | 결의 눈 | E 품질+3 |
| T03 | 차분한 응대 | 담당 시 설명만족+10 |
| T04 | 튼튼한 체력 | 시술 피로×0.85 |
| T05 | 꼼꼼한 정리 | 정리 후 청결 회복+4, 정리+2분 |
| T06 | 빠른 정리 | 정리-3분, 회복청결-2 |
| T07 | 선생님 기질 | 같은 블록 동료1명의 교육시간-15분, 최저60 |
| T08 | 향의 기억 | 조향 담당일에 발주한 기유·약초 구매가-10% |
| T09 | 서두르는 버릇 | 시술-5분, 품질-3 |

장점 후보T01~T04/T07/T08 중1, 대가 있는 특성T05/T06/T09~T12 중1. T08은 준비 단계에서 조향 근무를 한 블록 이상 확정한 직원이 있을 때 그날 기유·약초 발주에만 적용한다. 동일 직원 수만큼 중첩하지 않는다. 실제 배치의 투입량은 그대로이고 할인된 매입원가를 제품원가에 반영한다. 해당 블록을 취소하면 할인 차액을 지급해야 하며, 현금 부족이면 블록 변경을 보류한다.

고정 멤버: 사장은 E예상품질+2, 레이나는 조향 배치시간-15분, 네르는 R숙련 획득×1.5(0.5 단위 누적). 이들은 일반 특성을 별도로 무작위 부여하지 않는다. 기존 설명과 실제 효과를 같은 문장으로 UI에 표시한다.
