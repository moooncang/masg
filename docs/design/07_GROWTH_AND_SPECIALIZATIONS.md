# 07. 성장과 전문화 개편 v0.2

기존 명성·직원 능력·군숙련을 유지하면서 **다음에 무엇을 바꿀지 고르는 성장**을 추가한다. 수치는 구현 전 초기값이다. 경제 계산은03, 근무·예약·재고는04, 이번 성장의 자격·진척·보상은 이 문서가 정본이다. 명성T0~T5와 전문화 인증L0~L3는 다른 축이다.

새 성장 재화는 추가하지 않는다. 사장 운영 과제와 자격은 조건 달성형이다. 기존 현금·경력·연구 기록·시간으로 비용을 지불한다. 반복 접속이나 오프라인 대기로 성장하지 않는다.

## 2. 다섯 전문화의 공통 계약

T2에서 전문화 S01~S05 중 하나를 선택한다. 처음 선택은 무료. 변경은 준비 단계1,500동, 다음3영업일 전환 상태로 모든 전문화 보너스와 인증 진척이 정지한다. 전환 중 기본 영업과 이미 맺은 계약은 가능하다. 전환 완료 전 재변경 불가. 다른 전문화의 인증·배운 운영법·이야기는 보존하지만 효과는 현재 정책만 적용한다.

정책 변경으로 시간을 줄이거나 늘리더라도 확정 예약의 가격·점유시간·재료 약속은 바꾸지 않는다. 예약에는 수락 당시 정책 ID·효과·비용을 함께 저장하고 완료할 때 그 묶음만 사용한다. 이전 정책 예약과 현재 정책의 이득을 합산하지 않는다. 이전 정책 예약은 이전·현재 어느 쪽의 새 인증 실적에도 포함하지 않는다.

S04와 S05는 주요 인물·고급 메뉴를 독점하지 않는다. 기본 조향과 기본 현장 지도는 모든 전문화에서 가능하다. 자격 증명, 인물 신뢰, 추가 서비스의 실력 조건을 정책 보너스로 무시할 수 없다.

### S03의 예약 비율을 실제로 계산하기

분모는 그날 영업에 개방한 모든 방의 가용분 합계, 분자는 준비 단계에서 현장 배정을 막아 둔 예약 전용 분이다. `예약 전용 분 / 가용분 ≥ 0.5`. 미판매 전용시간도 비용이므로 분자에 포함한다. 이 조건을 만족하지 못하면 S03으로 개점할 수 없고 전용시간을 추가하거나 그날 정책 효과를 끄는 선택을 준다. 진행 예약을 취소하라는 의미가 아니다. 임의로 한 방만 열어 비율을 높이는 것은 허용하되 총 처리량이 줄어드는 대가가 있다.

### S04의 생산물과 비용

- 향유 배치에 생산처(구매/자가생산), 생산 담당자, 원가, 유통기한을 보존한다. 사서 새 병에 옮겨 담아 자가생산으로 바꾸지 못한다.
- 해당 시술의 필수 향유가 모두 자가생산이면 H 정책만족+4. 향유가 없는 M06은 적용 대상이 아니다. 일부만 자가생산이면 만족 보너스0이지만 실제 자가생산 소비량에 검사비는 부과한다.
- 검사비는 소비 때 운영비용으로 기록한다. 구매원가에 다시 더해 이중 비용 처리하지 않는다. 폐기·생산 중단에는 검사비를 청구하지 않는다.
- F2의2배 산출은 재료도2배 사용한다. 시간 단축·특성 할인은03의 상한을 따른다. 완성 향유의 소매·도매 판매는 도입하지 않는다.
- 예: 레이나의 진정1병은 `(60-15)×0.9=40.5분`이지만 기본60분의70% 하한을 적용해42분, 재료70동. 사용 때 검사10동으로 직접 비용80동, 완제품 구매100동보다20동 낮지만42직원분을 쓴다. F2가 있으면 같은42분에2병, 재료140+사용검사20=160동. 생산이 항상 정답이 아니다.

### S05와 공통 현장 지도

현장 지도는 T1, 같은 서비스군 숙련3 이상 지도자와 숙련0~2 학습자가 있으면 모든 정책에서 가능하다. 학습자 본인도 메뉴 자격을 충족해야 한다. M01~M07 및 M13만 허용, 전문군·VIP·M08·M14~18은 지도 대상에서 제외한다.

1. 고객 생성 시 교육 참여 성향을 저장한다. C1~C4는60%, C5~C6는30%, C7~C8는0% 확률로 참여 가능하다. 동일 고객의 성향은 이후 방문에도 유지하고, 참여 의향이 없는 고객은 지도 후보에서 제외한다. 의향을 정보창에 표시하며 수락 여부를 반복 추첨하지 않는다. 동의 가능한 고객도 실제 예산·시간·메뉴 조건을 만족해야 한다.
2. 고객에게 학습자 담당·추가10분·가격 상한1.00을 사전 안내한다. 같은 조건의 일반 서비스를 선택할 수 있고 거절해도 불만 없음. 기존 예약을 교육용으로 강제 전환하지 않는다.
3. 방1개·학습자 전체시간·지도자 첫20분을 예약한다. 지도자는 같은 시각 다른 시술·조향·교육을 할 수 없다. 지도자의 시간은 지도로 예약된 구간 동안 일반 근무 피로를 적용한다.
4. 품질은 학습자의 능력으로 계산하고 현장 지도의 정책품질+3을 적용한다. 다른 정책품질과 합해+5 상한. 자격 대여나 지도자의 능력치 복사는 없다.
5. 일반 정책의 성장 보상은 기본 시술 점수만. S05가 활성인 경우 B 이상 완료에 학습자 군숙련+1·경력+1, 지도자 경력+2. 하루 학습자당2건, 지도자당2건까지만 추가 보상. 초과 건도 지도할 수 있으나 보너스 없음.
6. 기본 군숙련 점수에 S05 보너스를 더한 후 네르의1.5배를 적용하고 한 건 최대4점. 경력은 지도자·학습자별 기록하며 일반 시술 대금은 한 번만 발생한다.
7. 지도20분이 끝나야 지도자 해제. 취소 시 경력·숙련 보상0, 재시작으로 보상 횟수가 늘지 않는다. 동시에 진행할 지도조는 최대2개, 직원 정원8명 유지.

예: M01 지도는 시술40+정리10=학습자50분, 지도자20분, 방50분이다. 일반 시술은40직원분이므로 지도는 총70직원분으로30분을 더 쓴다. S05는 성장 속도의 대가를 현재 처리량으로 지불한다.

## 3. 전문화 인증 15단계

기본 정책 선택 시 L0. L1→L2→L3 순서, 각 단계 착수일 이후 새 실적을 누적한다. 다른 단계로 넘긴 초과실적은 재사용하지 않는다. 한 날 다음 단계까지 완료할 수 없다. 소정 비용은 도전 시작 때 지급, 미달성으로 자동 몰수되지는 않으며 기한이 없는 과제는 중단·재개 가능하다. 명시한 ‘연속’ 지표는 실패하면 해당 연속 구간만0으로 돌아간다.

인증 보상은 표의 운영법 해금·표식·새 도전 선택권이다. 명성·수요·품질에 또 상시 배율을 더하지 않는다. L3에 필요한 실적과 표본을 만족한 뒤7영업일 안에 인증 장면1회를 일지에서 직접 읽을 수 있다.

L3의 주간 목표 선택권은 해당 계열의 적격 의뢰1개를 다음 게시판3칸 중1칸에 지정하는 기능이다. 무상 보상이나 추가 계약 슬롯이 아니다. 같은 계열 후보가 전부 쿨다운이면 다음 갱신까지 대기한다.

## 4. 사장 운영법 12개

T1에 운영법 화면을 열고 장착칸1개, T2에2개, T3에3개. 같은 계열은 한 개만 장착한다. 배운 운영법은 언제든 준비 단계에서 교체할 수 있으나 적용 후3영업일 동안 해당 칸 교체 금지. 기존 예약·발주는 이미 확정한 비용·효과를 보존한다. 기본적인 취소·정지·자동휴식은 운영법 없이도 가능하다.

표의 일반 과제 또는 대응 전문화 인증 중 하나로 해금한다. 모든 일반 과제는 T1 이후의 유효 실적을 누적하며 동일 거래를 같은 조건에 두 번 세지 않는다. 해금 후 교육비는 운영법당500동·사장60분, 한 번만 지급한다. 이 시간에는 사장이 시술하지 않는다.

## 8. 저장·경제·전환의 경계

- 인증은 전문화별 누적·현재단계·구간통계·지급ID를 저장한다. 운영법은 학습·장착·교체 가능일, 자격은 직원ID별 소유·활성·시험 진행을 저장한다.
- 프로젝트는 단계·누적 납입금·작업분·영업 실적·완료ID를 저장한다. 제작비를 지출한 시설 투자와 운영 연구비는03의 회계 구분에 맞춘다. 프로젝트는 무형 운영 개발비로 운영비용, 운영법·자격도 교육비로 처리한다.
- 동일 건이 의뢰·프로젝트·인증에 동시에 기여하는 것은 허용한다. 현금 보상을 같은 목표ID에서 다시 받거나 완료 실적을 소급 생성하는 것은 불가하다.
- 직원 경력점수는 개인별이며 가게 전체 합산 점수가 아니다. 직무 자격에 적힌 경력 조건은 해당 직원의 누적 경력만 사용한다.
- 해고한 직원을 재고용하더라도 자격·실적은 직원ID에 귀속한다. 새 직원으로 바꾸어 최초 자격 보상을 반복하지 못한다.
- 재정 재시작 시 인증·배운 운영법·이야기는 기록으로 유지하고 장착효과는 보유시설·현직원 조건을 다시 확인한다. 미완료 프로젝트의 투자·실적은 동결하고 기본재정 안정화 후 재개한다. 진행 중 계약의 위약금 면제는 재정 재시작 안내에 포함하며 경제 도전 기록은 무효다.
