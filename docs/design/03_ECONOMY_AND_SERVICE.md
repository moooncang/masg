# 03. 고객·서비스·경제

> 모든 화폐는 동화 정수다. 금1=은10=동1,000. 표의 새 가격은 현재 코드의 대체 제안이며 아직 적용되지 않았다. 확률은 퍼센트, 시간은 게임 분이다. 금전 계산은 항목별 최종값에서 반올림하고 합산한다.

## 1. 자원과 회계의 정의

| 자원 | 획득 | 지출/감소 | 목적 |
|---|---|---|---|
| 현금 | 완료 대금·팁·의뢰·차입 | 구매·급여·유지비·환불·상환 | 생존과 투자 |
| 명성 | 만족 고객·첫 성취 | 일반 운영에서는 감소 없음 | 기능 해금 |
| 최근 평가 | 일별 만족의 이동평균 | 불만족·점주 취소 | 단기 수요·계약 자격 |
| 소문 | 설명 없는 전문 시술·프라이버시 불만 | 안내·방음·일별 감소 | 평판과 별개인 사회적 긴장 |
| 피로 | 근무·시술 | 휴식·퇴근 | 인력 처리 능력 |
| 신뢰 | 이야기·약속 이행 | 약속 불이행 | 인물별 협업 해금 |
| 재료 | 발주·조향 | 예약 점유 후 시술 소비 | 서비스 가능 여부 |
| 연구 기록 | 조건 충족 전문 서비스 | 연구 과제 착수 | 전문 서비스 해금 |

초기 현금 3,000, 기본 임대·공과금 하루300, 창업 직원 레이나·네르 각150/일, 사장은 별도 급여 없음. 창업 멤버 해고 불가. 현재 무료 창업 직원 정책을 바꾸는 제안이다. 메뉴 필수 소모품은 건별 원가이며, 기본 두 방 청결도100, 향유3병, 기본 천30개로 시작한다. 초기 재고는 장부상 원가를 가진 무상 자본으로 기록한다.

회계:

- 운영매출 = 완료된 시술 대금 + 팁 + 이행 완료 의뢰 보상. 미완료 예약 보증금은 매출 아님.
- 운영비용 = 실제 소비한 재료 원가 + 일할 급여 + 유지비 + 교육비 + 광고비 + 이자 + 계약위약금 + 보상금.
- 운영이익 = 운영매출 - 운영비용. 시설 구입은 투자 지출이며 운영비용에서 제외한다. v0.2는 감가상각을 계산하지 않는다.
- 현금변화 = 실제 수입 - 실제 지출. 대출은 수입 현금이지만 매출 아님. 재고 발주는 현금지출, 소비 원가는 별도다.
- 보증금은 ‘현금’과 ‘돌려줘야 할 예약금’에 동시에 표시한다. 구매 가능액은 현금-미이행 예약금-이미 확정된 당일 급여·유지비다. 이를 넘는 투자는 불가하다.
- 이미 비용 처리한 항목을 정산 때 다시 비용 처리하지 않는다. 환불은 해당 거래와 연결한다.

## 2. 8개 고객군

고객 생성 시 군→예산·인내심·취향→서비스 선택 순서. 종족은 별도 외형·대사 축이다. 예산은 표 범위의 균등 정수, 인내심도 범위 내 균등 정수. 한 방문의 예산은 팁을 포함한 총 지출 상한이다.

개인 취향은 ‘짧게/자세한 설명/조용히/담당자 선호’ 중 하나. 각 25%이며 첫 완료 후 기록된다. 취향이 미확인일 때 큰 감점을 주지 않고 기본 응대로 처리한다. 이후 취향을 맞추면 만족+5, 알려진 취향을 거슬러도 -5까지만.

## 3. 수요와 서비스 선택

### 3.1 방문 기회

09~21시 현장 방문 기회를 생성한다. 기본 기대 건수/일은 T0=12, T1=18, T2=26, T3+=34다. 실제 처리 건수와 다르며, 예산·대기·메뉴 때문에 거절될 수 있다.

`기대 현장수요 = 기본수요 × 평가계수 × 행사계수 × 계절계수 × 광고계수 × 전문화 현장계수`.
평가계수 = `clamp(0.6 + 최근평가/125, 0.6, 1.4)`; 평가70이면1.16. 행사계수 0.7~1.8, 광고계수 최대1.25, 전체 배율은 기본수요 대비0.5~2.0으로 제한한다. 고객군 선호 가중치와 전체 수요 배율을 혼동하지 않는다.

예측량은 전날 준비에서 ±20% 범위로 안내한다. 각 날 저장된 난수로 총량을 기대값의 0.8~1.2배 범위에서 뽑고 반올림, 시간대 09~13시25%/13~17시35%/17~21시40%로 분배한다. 남은 반올림 건은 마지막 시간대로 보낸다. 시간대 안에서 도착분을 뽑고 정렬한다. 만석이어도 방문 기회는 사라지지 않고 ‘현장 거절’ 통계에 남는다.

예약 후보는 T1=4/T2=8/T3+=12명/일, 현장수요와 별도 풀이다. 실제 수락은 공간·인력·재료가 허용하는 한도다. 마케팅 예약 배율은 없다. 확정 예약은 현장수요 감소 사건으로 삭제하지 않는다.

### 3.2 메뉴 선택

활성 메뉴는 최대6개. 해금한 메뉴를 준비 단계에서 편성한다. 서비스는 아래 선호 메뉴 중 하나이거나 기본 근육풀이어야 후보가 된다.

| 고객군 | 선호 메뉴 ID |
|---|---|
| C1 | M01, M02, M13 |
| C2 | M01, M03, M13, M14 |
| C3 | M01, M04, M13, M14 |
| C4 | M05, M06, M07, M15, M16 |
| C5 | M03, M04, M09, M14, M17 |
| C6 | M04, M09, M14, M17 |
| C7 | M09, M10, M11, M12, M17, M18 |
| C8 | M07, M08, M10, M12, M16, M18 |

선호 메뉴는 매력점수의 선호서비스 +25를 받는다. 공통 대체 메뉴인 M01이 선호 목록에 없으면 이 보너스는 없다.  자격·재료·영업시간·예산 조건을 충족하지 못하면 후보에서 제외한다.

후보 매력점수 = `기본50 + 선호서비스25 + 알려진 개인취향 충족10 + 예상품질 보정 + 가격 보정 - 예상대기 보정`.
예상품질 보정=`clamp((예상품질-70)/2,-15,15)`.
가격 보정=`clamp((1-체감가격비율)×50,-20,15)`.
체감가격비율=고지가/기준가. 예약 살롱의 예약은 분모를 기준가×1.10으로 한다.
예상대기 보정=`min(30, 예상대기/2)`.

점수가 가장 높은 후보를 선택, 동점은 낮은 가격→짧은 소요→ID 순. 최고점35 미만이면 입장하지 않는다. 메뉴 없는 손님에게 유료 시술을 강제하지 않는다. 거절 이유를 예산/메뉴 부적합/대기/시간 부족/재료 부족으로 정확히 나눈다. 미래판에서 선택 다양성을 늘릴 수 있으나 첫 버전은 설명 가능한 결정식을 쓴다.

### 메뉴가 서로 대체되지 않는 이유

M01은 낮은 원가·넓은 예산·짧은 시간, M03은 모험가 적합성, M06은 체력 소모가 적은 휴식군, M09는 중간 숙련의 전문 입문, M10 이상은 예약·자격·재료·기대품질을 요구한다. 고가 메뉴의 이익/시간만 높여서 모든 고객을 전문 시술에 넣지 못하게 한다.

## 5. 품질과 만족

### 5.1 시술 품질 Q

군별 실력 E:

- R: 손기술×0.55 + 감각×0.25 + 친절×0.20.
- H: 손기술×0.25 + 감각×0.25 + 친절×0.50.
- E: 손기술×0.30 + 감각×0.60 + 친절×0.10.

`Q = clamp(round(60 + 7×(실력-난도) + 군숙련×2 + 시설품질 + 정책품질 + 직원품질 - 피로감점 - 청결감점 + 난수), 0,100)`.
군숙련0~5. 시설품질0~6, 정책품질 최대5. 직원품질은 담당자의 고유 보너스·특성·이야기·자격 효과를 합해 -3~+6으로 제한한다. 피로감점=max(0,(시작피로-40)×0.5), 최대25. 청결감점=max(0,(70-시작청결)×0.4), 최대20. 난수는 -4~+4 균등 정수로 예약 또는 배정 시 고정하고 저장한다. 재로드로 다시 뽑지 않는다.

등급 S≥90/A≥75/B≥60/C<60. 시술 시작 시 사용 직원·품질 재료·청결·피로를 스냅샷으로 잡는다. 도중에 가격·직원 배치를 바꿔 결과가 달라지지 않는다. 필수 재료가 없으면 시술 시작 불가이며 품질 감점으로 대체하지 않는다.

예: 사장(손5·감6·친4), R숙련0, M01 난도2, 피로20, 청결100, 시설0이면 실력5.05, 난수 전 Q=81.35. A가 기본이고 S가 자동 보장되지 않는다. 감각이 높은 직원도 M12 난도9를 교육 없이 안정적으로 처리하지 못한다.

### 5.2 고객 만족 S

`S = clamp(round(0.65×Q + 0.20×편안함 + 0.15×설명만족 - 대기감점 - 가격감점 + 취향보정 + 정책만족 + 추가만족),0,100)`.
편안함 기본70, 방음+10, 휴게 지원실+5, 청결<50이면-20, 0~100 제한.
설명만족 기본70, 접수 담당자 존재+10, 상담 지원실+10, 0~100 제한.
대기감점=max(0,실제대기-무료허용시간)×0.5, 최대25. 현장 무료허용10분/예약5분, C3·C6은 각각5/0분.
가격감점=max(0,체감가격비율-1)×40, 최대20. 취향보정 -5/0/+5. 정책만족은 S03 예약+5 또는 S04의 자가생산 향유 사용 H+4이며 두 정책을 중첩하지 않는다. S04의 향유 출처·검사비는07을 따른다. 추가만족은 사건·인물·허용된 운영 효과의 합이며 -10~+10으로 제한한다. 접수 담당자의 특성에 따른 설명 보정은 설명만족에 합산 후100 상한을 적용한다.

정시 시작=예약시각부터5분 이내. 고객 인내심이0이면 시술 시작 전 이탈하며 만족30으로 기록한다. 시작한 시술은 인내심으로 중단하지 않는다. 가격 불일치·사장 취소는 별도 실패 원인이며 모두 품질 실패로 집계하지 않는다.

대금은 고지한 가격 고정. C등급이면 대금20% 환급, 나머지 등급은 가격 배율 없음. 팁은 만족85 이상일 때 고지가×5%, 만족95 이상일 때×10%, 남은 예산 범위 내. C등급 환급과 팁이 동시에 생기면 팁은0이다. 환급·팁은 완료 거래에서 한 번만 확정한다.

### 5.3 최근 평가와 소문

당일 만족 평균은 완료 건과 대기 이탈·점주취소를 포함한다. 입장 전에 예산 부족으로 거절한 고객은 평가에 포함하지 않는다. 초기평가70으로 시작하고 `새 평가 = 기존평가×0.8 + 당일평균×0.2`. 평가 대상0건인 휴무일은 그대로다.

전문 시술 완료 시 설명만족<80이면 소문+1, C등급이면 추가+1. 방음이 없는 M08/M10~12/M17/M18은 건당+1. 방음은 이 프라이버시 항목만 제거한다. 일 종료 -4, 상담 기록실이 하루240분 운영되면 추가 -2. 0~100 제한. 50에서 경고, 70에서 **다음 날 감찰 예고**, 즉시 강제 폐업하지 않는다. 감찰 상세는 사건EV12.

## 6. 손익 검산과 투자 속도

다음은 수요·품질 시뮬레이션 결과가 아닌 고정 가정 계산이다. 처리 능력 식은 `(시술시간+정리시간)×건수 ≤ 직원/방 가용분`이며 예약과 현장을 합친다. 예측 수요가 있어도 처리 능력·예산을 못 넘는다.

| 경우 | 완료건×평균단가 | 평균원가 | 일 고정비 가정 | 운영이익(팁·환급·사건 제외) |
|---|---:|---:|---:|---:|
| 초반 안정 | 12×270=3,240 | 12×65=780 | 기본300+창업급여300=600 | 1,860 |
| 초반 부진 | 6×230=1,380 | 6×45=270 | 600 | 510 |
| 초반 심한 부진 | 2×200=400 | 2×20=40 | 600 | -240 |
| 중반 | 24×470=11,280 | 24×135=3,240 | 1,900(아래) | 6,140 |
| 후반 | 38×700=26,600 | 38×220=8,360 | 4,300(아래) | 13,940 |

중반 고정비: 기본300+창업300+일반직원2명×400+추가방2×150+지원실2×100=1,900.
후반: 기본300+창업300+일반직원4명×550+추가방2×150+지원실4×200+상위시설유지400=4,300.

24건×평균(45+10)분=1,320방분. 4방의 기본09~21시 총2,880방분 안에 든다. 38건×(55+10)=2,470방분으로 상한에 가까워 예약·휴식·청소가 중요하다. **전체 장부상 평균 가동률만으로 시간대 병목을 숨기지 않는다.** 저녁에 몰리면 하루 여유가 남아도 이탈한다.

이 초기 표에서는 중·후반 현금 축적이 빠를 위험이 있다. 따라서 검증 항목은 ‘모든 투자를 10일 만에 끝내는가’이다. 문제가 발생하면 수요 구성·재료·숙련 요구·투자비 순으로 조정한다. 내용 없는 가격 인플레이션이나 매일 세금 증가는 쓰지 않는다. 후반 소득은 지원실 재배치·인력 교육·계절 프로젝트의 선택 비용으로 소비한다.

## 7. 투자 회수와 광고

추가방은 **실제로 놓친 고객 중 방 부족 건수**로만 증분 매출을 추정한다. 3호실 비용6,000/일유지150, 하루 추가처리2건×기여이익200이면 순증250, 회수24일. 추가처리6건이면 순증1,050, 회수5.7일. UI는 이 범위를 보여주며 방이 비는데 직원이 없으면 고용을 우선 제안한다.

광고는 ‘없음/동네 전단200동·수요×1.10/상권 공지500동·수요×1.25’ 중 하루 하나, T1 해금. 준비 단계 비용 지급, 해당 영업일만 유효. 목표 고객군을 하나 골라 군 가중치×1.25도 적용한다. 추가 손님이 미수락이면 광고비는 회수되지 않는다. 자동 광고는 전날 가동률70% 미만·가용현금이3일 고정비 이상일 때만 집행할 수 있다.

## 8. 회생과 부채

일 종료 지급에 현금이 모자라면 지출을 삭제하지 않고 미지급금으로 기록한다. 다음 준비에서 투자·광고는 잠기지만 기본 영업은 가능하다. 직원은 첫 미지급일 즉시 이탈하지 않는다.

- 긴급 신용: T0부터 가용, 최초 한도3,000. 합산 원금 한도6,000. 하루 이자 미상환원금×0.5%, 반올림. 7일마다 원금의 계약시점20%를 청구한다. 연체 이자는 중첩하지 않고 연체 원금만 남긴다.
- 정산 잉여가 있으면 미지급 급여→운영비→이자→기한 도래 원금 순으로 지급. 임의 조기 원금 상환 가능, 수수료 없음.
- 현금≤0이며 미지급 상태3일이면 회생 제안: 3일 임대료 면제(기본300 중 임대200만), 천20개 외상 지급, 광고·확장 정지. 30일에1회. 외상400은 미지급금에 추가한다.
- 중고 매각: 추가 설비 구매가50%, 공사·스토리 보상·초기방은 매각 불가. 진행 예약을 깨는 방은 판매 전에 재배정/환불 해결 필요.
- 기본 모드에서 저장 삭제나 영구 게임오버는 없다. 계속 어려우면 ‘재정 재시작’으로 같은 외형·이야기를 보존하고 현금3,000/기본시설/부채0으로 돌아갈 수 있으나 해당 연도 경제 도전 기록은 무효라고 미리 알린다.

대출·회생 재고·중고 매각을 매출로 집계하여 계약 보상을 얻을 수 없다.

## 9. 수치 처리 공통 경계

`clamp(값, 최소, 최대)`는 범위 밖 값을 가까운 경계로 제한한다. 확률 보정의 %p는 덧셈, ×배율은 곱셈이다. 동일 효과 ID는 한 번만 적용한다. 시간은 기본값에 고정 분 증감을 먼저 적용한 뒤 배율을 적용한다. 시술·정리·조향은 원래 기본시간의70%보다 짧아지지 않도록 제한한 뒤 반올림한다. 교육·시험·연구는 해당 항목의 고정시간과 별도 최저값을 따른다. 시술시간 최소15분, 정리시간 최소5분, 조향시간 최소30분. 피로 감소 배율의 총 감소량은30% 상한, 회복속도 향상은 이 상한과 별개다. 제품 유통 연장 효과의 총합은 기본 대비 최대4일이며 이미 입고된 제품에 소급 적용하지 않는다(EV09의 개별 재밀봉만 명시적 예외). 비용 할인은 중첩 곱셈하되 최종30% 상한이다.

기존 가동시간 내 정리·청소·교육·생산은 직원 가용시간을 함께 사용한다. 총 처리량을 계산할 때 같은 직원을 동시에 두 곳에 세지 않는다. 계약 보상은 완료 보상과 시술 대금을 별개 거래 유형으로 기록하며 총 영업이익에는 포함한다.

## 10. v0.2 새 서비스의 선택 이유와 비용 경계

새 메뉴도 활성6개 안에서 골라야 한다. M13은 짧은 시간에 맞추되 M02보다 비싸고 어렵다. M14는 M04보다 빠르지만 가격이 낮고 원료2개가 필요하다. M15/M16은 생산 투자와 H숙련으로 성장하며 자가생산 없이 구매로도 운영할 수 있다. M17은 M11보다 낮은 난도와 가격의 전문 중간 과정, M18은 M12와 다른 향유·기록 원가 조합이다.

각 고객에게 방문 필요 태그 하나를 둔다. C1~C3는 ‘짧은 휴식’ 확률35%, C2/C5/C6는 남은 확률 중 ‘여정 회복’40%, C4/C8는 ‘향기 휴식’50%, C7은 ‘상세 설명’50%, 나머지는 일반이다. 태그를 순서대로 한 번만 추첨하고 저장한다. 짧은 휴식은 M02/M13, 여정 회복은 M03/M14, 향기 휴식은 M07/M15/M16, 상세 설명은 M09/M17/M18에 매력점수+12를 준다. 예산·개인 취향·자격은 그대로이며 이 보정은 만족을 직접 올리지 않는다. 신규 메뉴가 목록에만 존재하고 자동 선택에서 항상 밀리는지 검수한다.

S04 검사비는 실제 자가향유 소비1병당10동의 별도 운영비용이다. S05는 한 시술의 매출을 지도자와 학습자에게 이중 계상하지 않는다. 자격시험·운영법 학습·프로젝트는 운영 교육·개발비이며 시설 설치와 별도로 기록한다. 큰 프로젝트를 시작한 날의 적자를 기본 영업 부실과 구분해 보여준다.

품질의 정책품질에는 현장 지도+3을 포함하고 합계+5를 넘지 않는다. 설명만족에는 JC03/JC08 등 실제 담당자 효과를 더한 뒤100 상한. 능력10·군숙련5·시설품질6·직원품질6·추가만족10 상한을 그대로 유지한다. 효과 적용 시점은 거래 수락/시작 시 스냅샷으로 저장하여 장착을 바꾸면서 한 거래에 보너스를 겹치지 못하게 한다.
